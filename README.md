## 🌟 Ключевые возможности

### 1. 🌌 Интерактивная Натальная Карта (Zodiac Wheel Engine)

- **SVG-колесо Зодиака:** 12 секторов со стихийной цветовой кодировкой (Огонь 🔴, Земля 🟤, Воздух 🔵, Вода 🟣).
- **12 Астрологических Домов:** Римская градуировка домов (I–XII) с расчётом Асцендента (ASC) и Середины Неба (MC).
- **Хорды аспектов:** 5 мажорных аспектов — Соединение (0° ±8°), Секстиль (60° ±6°), Квадратура (90° ±7°), Трин (120° ±8°), Оппозиция (180° ±8°).
- **10 небесных тел:** Солнце ☉, Луна ☽, Меркурий ☿, Венера ♀, Марс ♂, Юпитер ♃, Сатурн ♄, Уран ♅, Нептун ♆, Плутон ♇.
- **Динамическая тап-инспекция:** При тапе на планету открывается карточка с точными градусами, ролью и кнопкой `«✦ Спросить»`, мгновенно открывающей чат с наставником.
- **Баланс стихий и крестов:** Автоматический расчёт распределения планет по 4 стихиям и 3 модальностям (кардинальный, фиксированный, мутабельный).

### 2. 🔮 Храм Таро — 78 карт Райдера-Уэйта

- **Полная каноническая колода:** 22 Старших Аркана + 56 Младших Арканов (Жезлы, Кубки, Мечи, Пентакли) с физическими изображениями высокого разрешения.
- **3D-анимация переворота карт:** Реалистичная механика раскрытия с золотым ореолом.
- **5 режимов раскладов:**
  - *Карта дня* (`daily`) — детерминированный суточный сид по ID пользователя, 1 карта.
  - *Оракул Да / Нет* (`oracle_yes_no`) — мгновенный вердикт с цветовым бейджем.
  - *3 Карты* (`three_cards`) — Прошлое, Настоящее, Будущее.
  - *Отношения* (`love`) — 5 карт: Состояние, Его мысли, Динамика, Барьер, Исход.
  - *Кельтский крест* (`celtic_cross`) — глубинный разбор из 10 карт.
- **Перевёрнутые карты:** Вероятность 28%, криптографическая случайность через `node:crypto`.

| Категория | Триггеры | Действие |

| **FINANCIAL_SCAM** | 100% выигрыши, казино, ставки, микрозаймы | Отказ от гарантий, фокус на натале |
| **BLACK_MAGIC** | Привороты, порча, проклятия, дата смерти | Деконструкция суеверий, свобода воли |

## 🔒 «Золотой Замок» (Правило 10 GEMINI.md)

Конфигурация запуска Mini App **защищена от любых изменений** (LOCKED & IMMUTABLE):

1. **`vercel.json`:** `"framework": null`, `"buildCommand": ""`, `"outputDirectory": "public"`, прямые rewrites без HTTP-редиректов. Корень `/` отдаёт `index.html` с HTTP 200 OK.
2. **`public/max-web-app.js`:** SDK моста раздаётся локально с собственного домена.
3. **`notifyBridge()`:** в `<head>` динамически отправляет мульти-сигнал готовности в 4 канала (`WebApp`, `WebViewHandler`, `WebKit`, `postMessage`), циклически каждые 100мс первые 5 секунд.
4. **Чат бота:** **100% Zero-Inline-Buttons** — вход строго по нативной кнопке `«✦ Открыть»` внизу слева. Никаких инлайн-ссылок, никаких URL в тексте.

## 🚀 Запуск и тестирование

### Установка зависимостей
```bash
npm install
```

### Локальный запуск (Express + Long Polling бота)
```bash
npm start
```
Сервер запустится на `http://localhost:3000`.

### Запуск полного набора автоматических тестов (RLVR)
```bash
npm test
```
Все 62 теста выполняются локально с проверкой целостности данных, API, файлов и безопасности.

### Сквозной прогон в реальном WebView со скриншотами
```bash
node test/verify_flow.cjs
```
Полный E2E-прогон: онбординг → натальная карта → Таро → чат с наставником. Скриншоты каждого экрана сохраняются автоматически.
